# Synthesis lesson (integrated essay)

For a topic, or for a set of chapter lessons. File name:
`<topic_slug>_synthesis_lesson.md` (or `<book_slug>_synthesis_lesson.md`).
Save it with the notes it draws on, e.g. `Orthodox/Lessons/` for a topic.

Rules:
- Build every claim from the vault notes and cite them. If a step needs something the notes do not have, mark the sentence ⚠ and add it to a closing `## Not Sure / Check These` list instead of presenting it as from the notes.
- Leave out the Key Figures Index when no figures matter to the argument.
- Scripture references come from the notes. Do not add verses from memory without the ⚠ mark.
